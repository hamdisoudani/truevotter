# Reddit Vote Tracker Chrome Extension

## Installation
1. Open Chrome and go to chrome://extensions/
2. Enable Developer mode
3. Click 'Load unpacked' and select this directory
4. The extension will be installed and ready to use

## Usage
1. Navigate to any Reddit page (www.reddit.com or old.reddit.com)
2. Click on upvote or downvote buttons on posts
3. The extension will automatically track these votes and send them to the backend
4. View tracked data in the popup or dashboard

## Features
- Tracks upvotes and downvotes on Reddit posts
- Sends data to local backend server
- Shows statistics in extension popup
- Links to full dashboard for detailed analytics
